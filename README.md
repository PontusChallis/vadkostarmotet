# Vad kostar mötet?

En liten webbapplikation som räknar ut vad ett möte kostar i realtid, baserat på deltagarnas månadslöner och hur länge mötet pågår.

## Funktioner

- Lägg till deltagare med namn/titel, månadslön och antal (t.ex. "Sjuksköterska x5")
- Ta bort deltagare från listan
- Starta, stoppa och nollställ en timer för mötets längd
- Se den totala kostnaden uppdateras live medan mötet pågår
- Valfritt: lägg till arbetsgivaravgift (31.42 %) på totalkostnaden

## Teknik

Byggd med React, TypeScript och Vite.
